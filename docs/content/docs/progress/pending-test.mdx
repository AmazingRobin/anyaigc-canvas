# 待测试

- 动态模型列表：分别使用模型权限不同的媒体 Key 与文本 Key 打开设置，确认页面自动刷新，也可手动点击“获取模型”；图片/视频只显示媒体 Key 返回且画布已支持的模型，文本只显示文本 Key 返回且明确支持 Responses 的模型。更换任一 Key 后旧列表和旧默认模型必须立即清空，另一 Key 的列表不得受影响；401/403 应清空对应列表，同 Key 的临时网络或后端失败则保留上次成功结果。
- v0.4.17 Grok 基础视频五模式：分别验证 `text-to-video`、`image-to-video`、`reference-to-video`、`edit-video`、`extend-video` 的创建、轮询、完成、失败、content 下载和失败重试；请求必须保留正式模型名与显式 `mode`，不得出现 `response_id` 或回落到其他模型。
- v0.4.17 输入边界：文生不携带媒体；单图生恰好 1 张图；Reference 使用 1/2/7 张图且最长 10 秒；编辑使用单个 MP4 且最长 8.7 秒；延长使用 2–15 秒 MP4 并选择 2/6/10 秒新增时长。非法数量、MOV、缺失 metadata 和越界时长应在提交前明确拒绝。
- v0.4.17 规格与计费：基础版只显示 480p/720p，1.5 继续显示并成功生成 1080p；生成类 Canvas 只显示 16:9/9:16/1:1，编辑与延长隐藏比例和分辨率；编辑按 `ceil(源视频真实秒数)`、其余按所选 duration 计费，所有 Grok 视频均不得加收异步 4 倍。
- v0.4.17 持久化与双语：刷新恢复、历史复用、任务续跑、画布节点和失败重试均保持原生成模式；从“我的素材”插入视频后必须保留 MP4 MIME、体积和精确源时长并可直接用于编辑/延长；中英文逐项检查模式、参考素材要求、输出规格、时长、错误、历史标签、设置弹层和 aria-label，不得出现中文残留、中英夹杂或 `Height`。
- v0.4.17 回归：`grok-imagine-video-1.5` 仍必须且只能使用 1 张图片，VEO 参考图继续执行 500KB 压缩；现有 Grok 图片、VEO、Nana、Seedance 和普通同步/异步视频行为不变。
- v0.4.16 双语回归：在生产环境分别以中文和英文覆盖首页、图片创作台、视频创作台、素材、提示词库、画布库、画布编辑器、设置与 404；重点验证语言往返切换、Ant Design 弹窗/下拉 Portal、辅助属性，以及带真实持久化数据的“回收站 N”和置顶/取消置顶标签不会残留另一种语言。
- 媒体失败记录：验证 Seedance 各类动态参考视频校验、Gemini 带动态拒绝原因的失败记录在中英文间双向切换；未知上游错误及用户提示词必须始终保持原文。
- Canvas Agent：分别验证在线 Agent 与本地 Agent 的 SSE / MCP / HTTP 错误、工具摘要、连接错误和诊断日志在切换语言后重算显示，用户消息、模型回复、工作区路径和上游错误不得被误译。
- Grok 视频比例：英文和中文界面均只展示横屏 / 竖屏 / 方形，并确认实际请求分别为 `16:9`、`9:16`、`1:1`；旧比例设置按方向归一。
- VEO 参考图：本地图片和 RelayBases 公共素材在提交前自动压缩到 500KB 限制内，需验证 `veo-3-1`、`veo-omni-flash`、`veo-omni-flash-video-edit` 的首次生成与失败重试；其他视频模型应保持原图上传。
- Codex App 插件文档：新增插件安装教程，区分 AI 自动安装、手动安装和本仓库开发调试安装；同步优化插件 README 与技能说明。
- 配置与用户偏好：每个模型渠道新增 OpenAI / Gemini 调用格式选择，默认 OpenAI，切换默认格式时同步更新默认 Base URL；渠道 Tab 增加紧凑醒目的提醒，说明模型是否可选需要到“模型”Tab 选择。
- Gemini 调用格式：支持拉取 Gemini 模型列表，并用于文本问答、在线 Agent 工具调用、基础生图和图生图请求。
- 音频和视频生成：选择 Gemini 调用格式时先给出不支持提示，仍需使用 OpenAI 兼容渠道。
- 移动端滚动体验：全局隐藏滚动条仅在精细指针设备生效，手机触摸设备保留原生滚动行为，需验证首页、生图工作台和视频工作台的纵向滑动是否顺畅。
